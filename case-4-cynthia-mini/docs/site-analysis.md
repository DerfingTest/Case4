# Анализ сайта Cynthia

Я рассматривала Cynthia как WEB-сайт для организации подбора персонала. Анализировала только то, что видит обычный пользователь, без разбора внутренней реализации исходной системы.

## Основные разделы

- вход и личный кабинет пользователя;
- главная страница с показателями подбора;
- список и карточки вакансий;
- база и карточки кандидатов;
- этапы рассмотрения кандидатов;
- сообщения, файлы и отчёты;
- управление сотрудниками и правами доступа.

## Возможные действия пользователя

Рекрутер может создавать вакансии, добавлять кандидатов, связывать кандидата с вакансией и изменять этап подбора. Руководитель может просматривать общие показатели и контролировать состояние вакансий. Администратор управляет пользователями и настройками сайта.

## Что я выбрала для Cynthia Mini

Для учебного сайта я оставила только основную цепочку работы:

- главная страница с показателями;
- вакансии;
- кандидаты;
- отклики кандидатов;
- воронка подбора;
- история изменения этапов.

Cynthia Mini я сделала как самостоятельный учебный проект, а не как копию дизайна исходного сайта.
