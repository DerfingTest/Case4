# Кейс-задача № 1 — массив

## Техническое задание

Дан одномерный массив `A` размерности `N`. Необходимо найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами массива. Максимальный и минимальный элементы в сумму не включаются.

Ответом на задачу является ссылка на репозиторий GitHub, в котором хранится программа, либо результат, переданный другим удобным способом.

## Решение

Программа:

1. считывает количество элементов `N`;
2. последовательно считывает элементы массива;
3. находит индексы первого минимального и первого максимального элементов;
4. определяет границы участка между ними независимо от порядка расположения;
5. суммирует только отрицательные элементы внутри этого участка.

Если минимальное или максимальное значение встречается несколько раз, используется индекс его первого вхождения. Для пустого массива вычисление невозможно, поэтому `N` должно быть больше нуля.

## Выводы

- Для решения не нужно сортировать массив: программа работает с исходным порядком элементов и поэтому не теряет их позиции.
- Неважно, какой экстремум расположен раньше. Левая и правая границы определяются по индексам минимального и максимального элементов.
- Минимальный и максимальный элементы служат только границами и в сумму не входят.
- Положительные числа и нули внутри выбранного участка пропускаются. Если между границами нет отрицательных элементов, результат равен `0`.
- Методы `min()`, `max()` и `index()` делают решение простым и понятным. При повторяющихся экстремумах `index()` выбирает первое вхождение, что важно учитывать при анализе результата.
- Алгоритм несколько раз проходит по массиву, но не использует вложенные циклы. Его временная сложность линейная — `O(N)`, а память для хранения введённого массива — `O(N)`.
- Проверка `N > 0` необходима: функции `min()` и `max()` нельзя применять к пустому массиву.

## Запуск

Требуется Python 3. Запустите команду из корня репозитория:

```bash
python case-1-array/main.py
```

Пример входных данных: `N = 8`, массив `[4, -3, 12, -5, -7, 2, -1, -10]`. Между максимальным элементом `12` и минимальным элементом `-10` находятся отрицательные числа `-5`, `-7` и `-1`; их сумма равна `-13`.
