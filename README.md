# Кейс-задачи № 1–5

В этом репозитории я собрала пять учебных работ: две программы на Python, базу данных, сайт на Delphi и обзор готового решения.

## Кейс-задача № 1 — массив

В [`case-1-array`](case-1-array) я сделала программу на Python, которая считает сумму отрицательных элементов между минимумом и максимумом массива.

- исходный код программы;
- техническое задание и описание алгоритма;
- инструкция по запуску;
- скриншот выполнения.

Подробнее: [`case-1-array/README.md`](case-1-array/README.md).

## Кейс-задача № 2 — наследование классов

В [`case-2-inheritance`](case-2-inheritance) я показала работу базового класса `Employee` и дочернего класса `Chief`.

- наследование методов;
- переопределение метода и вызов `super()`;
- собственный метод производного класса;
- скриншот выполнения.

Подробнее: [`case-2-inheritance/README.md`](case-2-inheritance/README.md).

## Кейс-задача № 3 — «Туризм»

В [`case-3-tourism`](case-3-tourism) я спроектировала базу MySQL для агентства путешествий к редким природным явлениям.

- четыре таблицы-справочника и одна таблица заказов;
- первичные и внешние ключи;
- ограничения `CHECK`, уникальные ограничения и индексы;
- демонстрационные данные и представление для отчётов;
- отчёт в формате DOCX.

Основной SQL-файл: [`case-3-tourism/tourism_rare_events.sql`](case-3-tourism/tourism_rare_events.sql).

## Кейс-задача № 4 — Cynthia Mini

В [`case-4-cynthia-mini`](case-4-cynthia-mini) я сделала учебный сайт для работы с вакансиями, кандидатами и откликами.

- серверная часть на Delphi 10.2 WebBroker;
- публикация через Microsoft IIS и ISAPI;
- база данных Microsoft SQL Server;
- браузерный интерфейс со сводной панелью, списками и воронкой подбора;
- SQL-скрипт создания и наполнения базы данных;
- отчёт и инструкция по запуску.
- пять скриншотов основных разделов сайта.

Инструкция по сборке и публикации: [`case-4-cynthia-mini/README.md`](case-4-cynthia-mini/README.md).

## Кейс-задача № 5 — обзор

В [`case-5-analytical-review`](case-5-analytical-review) я оценила Cynthia Mini по четырём критериям:

- функциональность;
- производительность;
- удобство использования;
- безопасность.

В отчёте я записала оценки, найденные ограничения и порядок дальнейших доработок. Мой итог: проект подходит как учебный прототип, но для реальной работы ему нужны авторизация, роли, HTTPS, безопасная обработка ошибок и полноценная серверная проверка данных.

Описание и скриншот: [`case-5-analytical-review/README.md`](case-5-analytical-review/README.md).

Отчёт: [`Кейс-задача№5_Обзор_Cynthia_Mini.docx`](case-5-analytical-review/Кейс-задача№5_Обзор_Cynthia_Mini.docx).
