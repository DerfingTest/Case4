# Кейс-задачи № 1–5

Репозиторий содержит пять учебных работ по программированию, проектированию баз данных, разработке WEB-сайта и обзору созданного решения.

## Кейс-задача № 1 — массив

Каталог [`case-1-array`](case-1-array) содержит программу на Python, которая вычисляет сумму отрицательных элементов одномерного массива, расположенных между его минимальным и максимальным элементами.

- исходный код программы;
- техническое задание и описание алгоритма;
- инструкция по запуску;
- скриншот выполнения.

Подробнее: [`case-1-array/README.md`](case-1-array/README.md).

## Кейс-задача № 2 — наследование классов

Каталог [`case-2-inheritance`](case-2-inheritance) содержит тестовую программу на Python, демонстрирующую работу методов базового класса `Employee` и производного класса `Chief`.

- наследование методов;
- переопределение метода и вызов `super()`;
- собственный метод производного класса;
- скриншот выполнения.

Подробнее: [`case-2-inheritance/README.md`](case-2-inheritance/README.md).

## Кейс-задача № 3 — «Туризм»

Каталог [`case-3-tourism`](case-3-tourism) содержит проект базы данных MySQL для агентства необычных путешествий к редким природным явлениям.

- четыре таблицы-справочника и одна таблица заказов;
- первичные и внешние ключи;
- ограничения `CHECK`, уникальные ограничения и индексы;
- демонстрационные данные и представление для отчётов;
- отчёт в формате DOCX.

Основной SQL-файл: [`case-3-tourism/tourism_rare_events.sql`](case-3-tourism/tourism_rare_events.sql).

## Кейс-задача № 4 — Cynthia Mini

Каталог [`case-4-cynthia-mini`](case-4-cynthia-mini) содержит учебный сайт для управления вакансиями, кандидатами и откликами.

- серверная часть на Delphi 10.2 WebBroker;
- публикация через Microsoft IIS и ISAPI;
- база данных Microsoft SQL Server;
- браузерный интерфейс со сводной панелью, списками и воронкой подбора;
- SQL-скрипт создания и наполнения базы данных;
- отчёт и инструкция по запуску.
- пять скриншотов основных разделов сайта.

Инструкция по сборке и публикации: [`case-4-cynthia-mini/README.md`](case-4-cynthia-mini/README.md).

## Кейс-задача № 5 — обзор

Каталог [`case-5-analytical-review`](case-5-analytical-review) содержит обзор сайта Cynthia Mini по четырём критериям:

- функциональность;
- производительность;
- удобство использования;
- безопасность.

В отчёте приведены оценки, выявленные ограничения и приоритетный план доработки. Итоговый вывод: проект подходит как учебный прототип, но до применения с реальными персональными данными необходимо реализовать авторизацию, роли, HTTPS, безопасную обработку ошибок и полноценную серверную проверку данных.

Описание и скриншот: [`case-5-analytical-review/README.md`](case-5-analytical-review/README.md).

Отчёт: [`Кейс-задача№5_Обзор_Cynthia_Mini.docx`](case-5-analytical-review/Кейс-задача№5_Обзор_Cynthia_Mini.docx).
