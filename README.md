# Кейс-задачи № 3 и № 4

Репозиторий содержит две учебные работы по проектированию информационных систем и баз данных.

## Кейс-задача № 3 — «Туризм»

Каталог [`case-3-tourism`](case-3-tourism) содержит проект базы данных MySQL для агентства необычных экспедиций к редким природным явлениям.

- четыре таблицы-справочника;
- одна таблица заказов;
- первичные и внешние ключи;
- ограничения `CHECK`, индексы и вычисляемая стоимость;
- демонстрационные данные и представление для отчётов;
- отчёт в формате DOCX.

Основной SQL-файл: [`case-3-tourism/tourism_rare_events.sql`](case-3-tourism/tourism_rare_events.sql).

## Кейс-задача № 4 — Cynthia Mini

Каталог [`case-4-cynthia-mini`](case-4-cynthia-mini) содержит учебный сайт управления подбором персонала.

- Delphi 10.2 WebBroker;
- Microsoft IIS и ISAPI;
- Microsoft SQL Server;
- браузерный интерфейс вакансий, кандидатов и воронки;
- SQL-скрипт создания и заполнения базы;
- отчёт в формате DOCX.

Инструкция по сборке и публикации находится в [`case-4-cynthia-mini/README.md`](case-4-cynthia-mini/README.md).
