# Tourism Rare Events

Учебная база данных «Туризм» для агентства необычных экспедиций к редким природным явлениям.

## Состав

- `tourism_rare_events.sql` — создание базы, пяти таблиц, связей, индексов, ограничений, демонстрационных данных и представления;
- `schema.md` — краткая схема связей и описание таблиц.

## Запуск в MySQL Workbench

1. Откройте MySQL Workbench и подключитесь к MySQL 8.0.16 или новее.
2. Выберите **File → Open SQL Script**.
3. Откройте `tourism_rare_events.sql`.
4. Выполните весь скрипт кнопкой с изображением молнии.
5. Обновите список схем и откройте `tourism_rare_events`.

Скрипт создаёт четыре справочника и одну таблицу переменной информации:

- `destinations`;
- `tour_themes`;
- `service_packages`;
- `travelers`;
- `tour_orders`.

В конце скрипта находятся контрольные SELECT-запросы.
