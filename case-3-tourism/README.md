# Tourism Rare Events

В этой работе я сделала учебную базу данных «Туризм» для агентства, которое организует поездки к редким природным явлениям.

## Состав

- `tourism_rare_events.sql` — создание базы, пяти таблиц, связей, индексов, ограничений, демонстрационных данных и представления;
- `schema.md` — краткая схема связей и описание таблиц.

## Как воспроизвести результат в MySQL Workbench

Я проверяла скрипт в MySQL 8.0.16. Чтобы воспроизвести результат, можно сделать так:

1. Открыть MySQL Workbench и подключиться к MySQL 8.0.16 или новее.
2. Выбрать **File → Open SQL Script**.
3. Открыть `tourism_rare_events.sql`.
4. Выполнить весь скрипт кнопкой с изображением молнии.
5. Обновить список схем и открыть `tourism_rare_events`.

В результате мой скрипт создаёт четыре справочника и таблицу заказов:

- `destinations`;
- `tour_themes`;
- `service_packages`;
- `travelers`;
- `tour_orders`.

В конце я добавила контрольные `SELECT`-запросы, по которым можно проверить загруженные данные и рассчитанные суммы.
