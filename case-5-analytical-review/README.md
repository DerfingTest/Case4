# Кейс-задача № 5 — обзор

## Описание

В этой работе я рассмотрела сайт Cynthia Mini из кейс-задачи № 4 и оценила его по четырём критериям:

- функциональность;
- производительность;
- удобство использования;
- безопасность.

В отчёте я отметила сильные стороны и ограничения, поставила итоговые оценки и составила план доработки. Получилась общая оценка `2,9 из 5`. Я считаю, что сайт подходит для учебной демонстрации, но перед работой с реальными персональными данными в него нужно добавить аутентификацию, роли, HTTPS, безопасную обработку ошибок и строгую серверную проверку данных.

Отчёт: [`Кейс-задача№5_Обзор_Cynthia_Mini.docx`](Кейс-задача№5_Обзор_Cynthia_Mini.docx).
